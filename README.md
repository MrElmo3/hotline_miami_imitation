# Hotline Miami Imitation

This project is a Unity-based imitation of the popular game Hotline Miami. The goal is to recreate the fast-paced, top-down shooter experience with similar mechanics and aesthetics.

## Introduction
Hotline Miami Imitation is a project aimed at replicating the core gameplay mechanics and visual style of the original Hotline Miami game. This includes top-down shooting, quick reflexes, and strategic planning.

## Features
- Top-down shooter mechanics
- Fast-paced gameplay
- Retro-inspired graphics
- Multiple levels and enemies
- Sound effects and music

## Installation
1. Clone the repository:
	```sh
	git clone https://github.com/yourusername/hotline_miami_imitation.git
	```
2. Open the project in Unity:
	- Open Unity Hub
	- Click on "Add"
	- Select the cloned project directory

## Usage
- Use the arrow keys or WASD to move your character.
- Use the mouse to aim and shoot.
- Press `R` to restart the level.
